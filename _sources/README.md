# Source Notes

Store distilled source notes here, not raw junk.

Use one folder per source:

```text
_sources/
  codrops/
  gsap/
  animations-dev/
  portfolio-studies/
```

Each source note should answer:

- What was scraped or reviewed?
- Which animation pattern is worth keeping?
- What makes it good?
- What makes it risky?
- Is the license clear?
- Did it pass the quality gate?

Do not paste large copyrighted articles or full source code here. Summarize the useful idea, then build an original local module if it passes.
