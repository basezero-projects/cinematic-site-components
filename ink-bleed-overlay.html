Module 44 - Ink Bleed Overlay

Open the overlay like ink spreading.

Use this for contact panels, project details, editorial menus, or campaign overlays when a normal dropdown would feel underbuilt next to a cinematic page.

The transition is the doorway.

A shader overlay is useful when it changes context. It should not hide weak content or replace ordinary navigation.

Contact layer

The page stays behind the ink.

The shader is pinned to screen space, so it behaves like an overlay rather than another 3D object. Use it when the visitor is entering a new mode: contact, booking, project detail, or an editorial menu.

InputClick/tap toggles one shader uniform and one HTML panel.
MotionNoisy radial spread with softer edges while the ink is moving.
FallbackReduced motion skips the shader and shows a normal overlay panel.

Why this belongs in the library.

This is a UI transition, not decoration. It gives future sites a way to open high-value overlays without snapping into a generic modal, while still keeping a plain reduced-motion path.
